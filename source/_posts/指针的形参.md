* 注意：`*p--=3`实际上是`*p=3`，然后`(p--)`

```
#include<iostream>
using namespace std;
int func(int *p){
	return (*p--=3)-1;
}
int main()
{
	int arr[]={10,7,5};
	int *p=arr+1;
	printf("%d",func(p)+*p);
        // 答案为5
}
```
